# Biodiary Web版

Android版Biodiaryと同じ共有APIを使う、スマートフォン向けブラウザ版です。iPhoneのSafariで使いやすいレイアウトと、ホーム画面に追加できるPWAの構成にしています。

## 起動

このフォルダをHTTPSで配信してください。PWAのホーム画面追加、写真・カメラ、位置情報、Service WorkerはHTTPS環境で利用できます（localhostを除く）。HTMLファイルを直接開く方法では、これらの機能が動かない場合があります。

特に地図はOpenStreetMap標準タイルを使うため、`file://` でHTMLを直接開くと、タイル利用条件に必要な `Referer` が送られず403になることがあります。HTTPSで配信されたページから開いてください。ページにはOSMFの推奨に沿ったReferrer設定を追加しています。

## 現在使える機能

- 1件につき最大4枚の写真。地図・図鑑は1枚目、詳細は写真の切り替えで表示。登録・編集画面で追加・取り外し・個別トリミングができます。

- OpenStreetMap地図と、季節色の写真ピン
- 地図タブの追加・切替
- 写真の撮影・選択、アップロード前の拡大と切り取り
- 現在地取得、地図タップによる場所指定
- 観察日時、場所メモ、コメント、ジャンル、種・学名・属・科・目
- GBIFの種候補検索と分類情報入力（オンライン接続が必要）
- 記録の編集・削除、季節フィルター、写真グリッド図鑑
- 共有写真の左上に投稿者のアイコンを表示し、「共有」フィルターでログイン名から地図・図鑑を絞り込み
- コミュニティタブに登録済みメンバーのログイン名、アカウントID、ひとことを表示
- 色付きタググループの作成・編集・削除
- プロフィール編集、JSONバックアップの書き出し・読み込み
- IndexedDBへの端末内保存、基本画面のキャッシュ

JPEG写真にEXIFの撮影日時・位置情報が含まれている場合は読み取ります。HEICなど一部の形式ではEXIF位置情報を自動で読めないことがあるため、その場合は現在地または地図タップで場所を指定してください。

## 保存とオンライン機能について

利用にはCloudflare側のアカウント作成またはログインが必要です。招待コードなしでアカウントを作成でき、Android版と同じログイン名・パスワードを使います。アカウント情報はCloudflare D1、端末内の未共有記録・写真はIndexedDB、共有した記録・写真とアイコン画像はRaspberry Piに保存します。共有記録の取得は「共有記録を同期」から手動で行います。写真の送受信は、Cloudflareが発行する短時間の署名付き認証情報を使って、ブラウザからPiのTailscale Funnelへ直接接続します。

コミュニティ参加はアカウント作成後にコミュニティタブで行い、参加時だけ一回限りの招待コードが必要です。参加前でも自分の地図と図鑑を利用できます。共有時には写真と撮影位置がメンバーに公開されます。場所の詳細を非公開にした記録は、県庁所在地を公開位置として使います。コミュニティタブの一覧は参加済みメンバーであり、現在オンライン中の人だけを示すものではありません。

Web版の変更を公開する際は、このフォルダの内容をCloudflare Pagesへ再デプロイしてください。公開後に古い画面が残る場合は、ページを再読み込みしてください。

地図タイルとGBIFの分類検索は通信を使います。画面の基本ファイルはキャッシュできますが、地図はオフライン表示に対応していません。OpenStreetMap標準タイルの利用ポリシーに従い、帰属表示を画面に載せています。
