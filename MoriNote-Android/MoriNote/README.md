# Biodiary — 自然観察アルバム

アカウントを作成して使う自然写真アルバムです。未共有の写真は端末内に保存します。

- OpenStreetMapを使った地図に、季節色の枠が付いた写真ピンを表示
- 春・夏・秋・冬を個別に選択し、複数の季節を同時に重ねて表示
- アプリからの撮影と、Androidの写真ピッカーからの写真登録
- 写真のEXIF情報から撮影日とGPS位置を読み込み
- GPS位置がない場合は、地図をタップして撮影場所を指定
- 生きものの名前を手入力し、GBIF検索で分類候補を入力
- 写真と記録を端末内に保存
- Cloudflareで招待コードなしのアカウント登録・ログイン。コミュニティ参加時にだけ招待コードを入力
- 選んだ観察記録をコミュニティへ共有し、写真とアイコン画像をRaspberry Piに保存
- サーバーにある自分やメンバーの記録を同期（端末だけの記録は自動送信しません）

## 開き方と起動方法

1. このフォルダをAndroid Studioで開きます。Gradle WrapperがGradle 8.13を選ぶので、初回同期時はダウンロードを許可します。
2. Androidエミュレーターまたは端末で `app` の実行構成を起動します。既にインストール済みの場合は同じアプリIDのまま更新されます。
3. 以前のアカウントを持っている場合は、同じログイン名とパスワードで「ログイン」を押します。新しい利用者はアカウント名・ログイン名・パスワードを入力して「作成」を押します。

地図にはOpenStreetMapのデータと公開タイルを使うため、Google Maps PlatformのAPIキーや課金設定は不要です。地図タイルの表示にはインターネット接続が必要で、OpenStreetMap標準タイルの利用ポリシーに従います。標準タイルはオフライン用に一括ダウンロードできず、サービスの稼働保証もありません。地図上に「© OpenStreetMap contributors」と表示します。

このプロジェクトではGradle 8.13を使います。Android Gradle Plugin 8.13.xに対応するため、Android StudioのGradle設定は「Gradle Wrapperを使用」にしてください。

## 現時点での制限

- 写真にGPS情報がない場合は、現在地を取得するか地図をタップして場所を指定します。
- 地図に表示する場所の名前は任意のメモとして入力します。記録を保存するときは座標も保存します。
- 地図の表示には通信が必要です。地図タイルは端末内に保存する観察記録とは別で、オフライン地図には対応していません。
- アカウント・参加状態はCloudflare D1に保存します。共有記録・写真とアイコン画像はRaspberry Piに保存します。
- 新しい記録は端末内だけに保存されます。記録カードの「共有する」を選び、写真と正確な位置情報を含む確認に同意した場合だけサーバーへ送ります。
- ブラウザとAndroidは共通アカウントで使えます。コミュニティ参加と同期はコミュニティタブから行います。
- Androidの内部アプリID `jp.morinote.app` は、既にインストールされたアプリとデータの更新互換性のため維持しています。アプリ名や画面上のブランド表示には使いません。
