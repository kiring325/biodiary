# Mori Note — Androidアプリの土台

端末内で使う自然写真アルバムです。現在、次の機能を含んでいます。

- OpenStreetMapを使った地図に、季節色の枠が付いた写真ピンを表示
- 春・夏・秋・冬を個別に選択し、複数の季節を同時に重ねて表示
- アプリからの撮影と、Androidの写真ピッカーからの写真登録
- 写真のEXIF情報から撮影日とGPS位置を読み込み
- GPS位置がない場合は、地図をタップして撮影場所を指定
- 生きものの名前を手入力し、画像ラベルの候補も表示
- 写真と記録を端末内に保存。アカウント別バックアップは今後の追加予定

## 開き方と起動方法

1. このフォルダをAndroid Studioで開きます。Gradle WrapperがGradle 8.13を選ぶので、初回同期時はダウンロードを許可します。
2. Androidエミュレーターまたは端末で `app` の実行構成を起動します。

地図にはOpenStreetMapのデータと公開タイルを使うため、Google Maps PlatformのAPIキーや課金設定は不要です。地図タイルの表示にはインターネット接続が必要で、OpenStreetMap標準タイルの利用ポリシーに従います。標準タイルはオフライン用に一括ダウンロードできず、サービスの稼働保証もありません。地図上に「© OpenStreetMap contributors」と表示します。

このプロジェクトではGradle 8.13を使います。Android Gradle Plugin 8.13.xに対応するため、Android StudioのGradle設定は「Gradle Wrapperを使用」にしてください。

## 現時点での制限

- 名前候補には、ML Kitの汎用画像ラベルを使います。生物の種を特定する専用モデルではないため、「鳥」「花」のような大まかな候補になることがあります。保存する名前はユーザーが入力・選択したものです。
- アプリで撮影した写真にGPS情報がない場合、地図をタップして場所を指定する必要があります。この初版では端末の位置情報へのアクセス許可は求めません。
- 地図に表示する場所の名前は任意のメモとして入力します。記録を保存するときは座標も保存します。
- 地図の表示には通信が必要です。地図タイルは端末内に保存する観察記録とは別で、オフライン地図には対応していません。
- アカウント、同期、バックアップ機能はまだありません。
